# SpeedReader: настольное приложение для чтения с бегущей подсветкой

Дата: 2026-10-24. Статус: согласован 2026-10-24.

## Зачем

Пользователь читает книги с loveread.ec по словам в заданном темпе: на экране
обычный текст, подсветка перепрыгивает со слова на слово, страница сама
прокручивается. Нужна программа, которую можно поставить одним файлом на
Windows и Ubuntu, которая помнит библиотеку скачанных книг и место, где
чтение остановилось.

## Цели

- Экран «Библиотека» на старте: список скачанных книг, у каждой «Продолжить»,
  «Начать заново», «Удалить»; кнопка «Добавить» открывает форму источника.
- Форма источника: поле URL и кнопка «Скачать»; кнопка «Загрузить PDF» есть,
  но выключена с подсказкой «скоро». Поддерживается только loveread.ec,
  другой URL даёт понятную ошибку. Скачивание идёт в фоне с прогрессом по
  страницам и кнопкой «Отмена», книга кэшируется локально. Рядом кнопка
  «Импорт JSON» для файла, который сохраняет `loveread_browser.js`: запасной
  путь на случай, если сайт перестанет отвечать скриптам.
- Экран чтения: текст книги целиком, текущее слово подсвечено, окно само
  прокручивается так, чтобы слово оставалось видно. Скорость задаётся
  ползунком в словах в минуту и меняется на ходу.
- Закладки: автоматическое сохранение позиции (при паузе, уходе в библиотеку,
  закрытии окна) и ручные закладки по кнопке со списком для перехода.
- Сборка в GitHub Actions по тегу `v*`: `SpeedReader.exe` для Windows и
  `speedreader_<версия>_amd64.deb` для Ubuntu, оба прикладываются к релизу.

## Не цели

- Чтение PDF и другие сайты: только точка расширения, без реализации.
- Синхронизация между устройствами, облако, учётные записи.
- Режим RSVP (слово в фиксированной точке), темы оформления, озвучка.
- macOS-сборка.

## Анти-цели (что сделает проект неудачным, даже если «работает»)

- Потеря позиции чтения: пользователь закрыл окно крестиком и начал книгу
  с начала.
- Зависание интерфейса во время скачивания.
- Повторное скачивание книги, которая уже есть локально.
- Установка, требующая от пользователя Python или командной строки.

## Ограничения

- Python 3.12, PySide6 (официальная привязка Qt 6, LGPL). Стандартная
  библиотека везде, где хватает.
- Парсер loveread уже написан (`loveread.py`, 32 теста) и переезжает в пакет
  без изменения поведения. Его схема JSON остаётся контрактом между
  источником и читалкой: `{id, title, author, source, pages, pages_fetched,
  complete, blocks: [{type: paragraph|heading, page, text}]}`.
- Тесты без дисплея: логика чтения и хранилища отделены от виджетов и
  проверяются `unittest`; виджеты проверяются дымовым тестом с
  `QT_QPA_PLATFORM=offscreen`.
- Windows-exe собирается только в CI (на машине разработчика Linux).
- Код комментируется по правилам из CLAUDE.md: комментарий только на «почему».

## Решения, принятые пользователем

- Режим чтения: обычный многострочный текст, подсветка прыгает по словам.
- Старт с библиотеки, а не с формы источника.
- Сборка Windows и Linux в GitHub Actions; репозиторий заводит пользователь.
- Windows-exe и deb-пакет, без установщика-мастера.

## Решения, принятые проектировщиком (можно оспорить)

### Структура

```

  __init__.py           __version__
  __main__.py           python -m speedreader
  app.py                QApplication, главное окно со стеком экранов
  library.py            LibraryStore: library.json + books/*.json
  reading.py            ReadingModel: слова, позиции, тайминги, навигация
  ui/library_page.py    экран библиотеки
  ui/add_page.py        форма источника + фоновая загрузка
  ui/reader_page.py     экран чтения
  sources/__init__.py   detect(url) -> Source | None
  sources/loveread.py   бывший loveread.py, без изменений логики

assets/icon.svg, icon.png, icon.ico, speedreader.desktop

.github/workflows/build.yml

```

### Хранилище

Каталог данных: `QStandardPaths.AppDataLocation` (`~/.local/share/SpeedReader`
на Linux, `%APPDATA%\SpeedReader` на Windows). Внутри:

- `books/<key>.json` — книга в схеме парсера, как есть.
- `library.json` — список записей:
  ```
  {"version": 1, "wpm": 250, "books": [
     {"key": "loveread-36708", "title": ..., "author": ..., "source_url": ...,
      "added_at": "2026-10-24T18:00:00", "complete": true, "word_count": 52000,
      "position": {"block": 12, "word": 3},
      "bookmarks": [{"block": 12, "word": 3, "created_at": ..., "label": "первые слова..."}]}
  ]}
  ```
  Запись пишется атомарно (во временный файл, потом `os.replace`), при
  повреждённом файле библиотека стартует пустой и переименовывает битый файл
  в `library.json.broken`.
- `key` даёт источник: для loveread это `loveread-<id>`. Повторное добавление
  того же URL открывает существующую книгу на сохранённой позиции вместо
  скачивания. Импорт JSON с тем же `id` тоже открывает существующую.
- В библиотеку попадают только книги с `complete: true`. Частичный результат
  не сохраняется ни при отмене, ни при ошибке сети: под полем URL остаётся
  текст ошибки с числом успевших скачаться страниц и предложение повторить.
- Если запись есть, а `books/<key>.json` не читается, строка библиотеки
  показывает «файл книги не найден», «Продолжить» выключена, есть «Скачать
  заново» (тот же `key`, позиция и закладки остаются) и «Удалить». Позиция и
  закладки при открытии обрезаются до последнего существующего слова.
- «Начать заново» сбрасывает только позицию, закладки остаются, без
  подтверждения. «Удалить» спрашивает подтверждение и стирает запись вместе с
  файлом книги. Закладка удаляется через контекстное меню списка; повторная
  закладка на том же слове не создаётся.
- Скорость `wpm` одна на приложение, не на книгу.

### Модель чтения

- Слово = последовательность непробельных символов внутри блока, в которой
  есть хотя бы одна буква или цифра. Токен из одних знаков («—», «…», «***»)
  приклеивается к предыдущему слову, в начале блока — к следующему. Так
  «сказал, —» одно слово. Позиция = `(block, word)`; правило разбиения
  входит в контракт `library.json` (`version: 1`) и закреплено тестами.
- Пауза на слово = `60 / wpm` секунд, умноженная на наибольший из
  множителей: 1.5 для слова с запятой, точкой с запятой, двоеточием или тире
  в конце, 2.0 для конца предложения (`.!?…` с учётом закрывающих кавычек и
  скобок), 2.5 для последнего слова блока. Заголовки читаются как обычные
  блоки.
- Навигация: Space — пауза/старт; ← — к началу текущего предложения, а если
  слово уже первое в нём, то предыдущего; → — к началу следующего (граница —
  слово, оканчивающееся на `.!?…`); ↑/↓ — предыдущий/следующий блок; Ctrl+B —
  закладка; Esc — в библиотеку; клик по слову переставляет позицию на него.
  Ручная прокрутка колесом или полосой ставит чтение на паузу; при старте
  окно снова центрируется на текущем слове.
- Таймер — один `QTimer.singleShot`, перезапускаемый после каждого слова;
  смена скорости ползунком влияет на следующее слово.
- Прогресс книги = прочитанные слова / все слова, показывается в библиотеке
  и в строке состояния читалки.

### Экран чтения

- `QTextEdit` только для чтения, документ строится один раз через
  `QTextCursor`: заголовки жирным и крупнее, абзацы с отступом; при вставке
  запоминается символьная позиция каждого слова. Подсветка — `ExtraSelection`
  с фоном на текущем слове, прокрутка `ensureCursorVisible` плюс центрирование
  при уходе слова в нижнюю треть окна.
- Панель внизу: кнопка пауза/старт, ползунок скорости 100–1000 с шагом 10 и
  числом рядом, кнопка закладки, выпадающий список закладок, кнопка «В
  библиотеку», прогресс в процентах.
- Шрифт — системный с засечками 16pt, ширина колонки текста ограничена
  ~80 символами, чтобы строки не растягивались на весь экран.

### Форма источника и загрузка

- Один `QThread` с рабочим объектом; рабочий вызывает `download_book` из
  парсера с `log`-колбэком, из сообщений `page N/M` берётся прогресс.
  «Отмена» ставит флаг, который проверяется в `opener`, передаваемом в
  `fetch`, то есть перед каждой HTTP-попыткой: худшая задержка — один таймаут
  запроса. Кнопка становится «Отмена…» и ждёт завершения потока. Закрытие
  окна во время загрузки ставит флаг, ждёт поток до 3 с и выходит.
- Ошибки парсера показываются текстом под полем URL; форма остаётся
  заполненной. Пока идёт загрузка, с формы уйти нельзя: «Назад» и Esc
  заблокированы вместе с остальными кнопками, но окно отзывчиво.
- После успешного скачивания или импорта открывается читалка с первого
  слова.
- «Импорт JSON»: диалог выбора файла, файл проверяется на схему парсера
  (`id`, `title`, `blocks` с `text`), копируется в `books/`, запись
  добавляется как для скачанной книги.

### Сборка

- `pyproject.toml`: зависимость `PySide6-Essentials>=6.7` (только QtCore,
  QtGui, QtWidgets), точка входа `speedreader = speedreader.app:main`.
- PyInstaller: `--windowed`, одна папка (`onedir`) для deb и один файл
  (`onefile`) для Windows. Spec-файл общий, режим задаётся переменной;
  неиспользуемые модули Qt и переводы исключены, цель — exe меньше 70 МБ.
  Exe не подписан: при первом запуске SmartScreen покажет «Неизвестный
  издатель», в заметках к релизу есть строка про «Подробнее → Выполнить в
  любом случае». Windows-задача запускает собранный exe с флагом `--smoke`
  (создать окно и выйти), чтобы поймать битую сборку до релиза.
- Deb: `/opt/speedreader/` с результатом PyInstaller, симлинк
  `/usr/bin/speedreader`, `/usr/share/applications/speedreader.desktop`,
  иконка в `/usr/share/icons/hicolor/256x256/apps/`. Собирается `dpkg-deb`
  на `ubuntu-22.04`, чтобы бинарник работал на 22.04 и новее. `Depends`:
  `libxcb-cursor0, libxkbcommon0, libgl1, libegl1, libfontconfig1,
  libdbus-1-3, libxcb-xinerama0`.
- Workflow `build.yml`: задача `test` (ubuntu, `python -m unittest`),
  затем матрица `windows-latest` и `ubuntu-22.04`, затем `release`, которая
  по тегу `v*` создаёт GitHub Release и прикладывает оба файла. Ручной запуск
  (`workflow_dispatch`) собирает артефакты с версией `0.0.0.dev<номер>` без
  релиза. Теги `vX.Y.Z` и `vX.Y.Z-<суффикс>`: `v` отбрасывается, суффикс
  даёт `~суффикс` в deb и `prerelease: true` в релизе. Версия записывается
  в `speedreader/__init__.py` на этапе сборки.
- Метаданные: Maintainer и authors — GitHub-логин владельца репозитория с
  адресом `<логин>@users.noreply.github.com`; файл LICENSE появляется только
  после выбора лицензии пользователем.
- Иконка: простой SVG (открытая книга с полосой подсветки), PNG и ICO
  генерируются скриптом из репозитория, результат закоммичен.

## Оставлено строителю

- Точный вид и расположение виджетов, тексты подсказок.
- Способ выделения предложений внутри слова с кавычками и скобками.
- Имена сигналов и слотов, разбиение на файлы внутри `ui/`.
- Дымовой тест offscreen: что именно в нём проверять.

## Ответы пользователя на вопросы строителей

1. Лицензия и файл LICENSE: откладываются до публикации репозитория. Пока в
   `pyproject.toml` нет поля `license`, Maintainer в deb — заглушка
   `SpeedReader <speedreader@example.invalid>`, заменяется перед первым
   релизом.
2. Подпись Windows-exe: не нужна, exe не подписан.
